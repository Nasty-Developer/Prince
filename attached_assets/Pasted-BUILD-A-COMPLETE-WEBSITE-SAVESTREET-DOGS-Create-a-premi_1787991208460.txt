BUILD A COMPLETE WEBSITE: SAVESTREET DOGS 🐾

Create a premium, modern, emotionally engaging, responsive animal-rescue website called:

SaveStreet Dogs

The website should be designed as a real-world platform dedicated to helping street dogs and puppies, supporting rescue efforts, spreading awareness, connecting animals with adopters, and allowing people to contribute through donations, volunteering, and purchases.

The website must NOT look like a generic template. It should feel like a carefully designed modern animal-welfare organization with excellent UI/UX, strong storytelling, accessibility, mobile responsiveness, and smooth interactions.

---

1. CORE PURPOSE

The main purpose of SaveStreet Dogs is:

- Help injured and abandoned street dogs
- Help vulnerable puppies
- Allow people to report dogs that need help
- Connect rescued dogs with potential adopters
- Encourage responsible adoption
- Provide food and basic support
- Promote vaccination and sterilization awareness
- Recruit volunteers
- Accept donations
- Sell animal-support products
- Share rescue stories
- Educate visitors about street-animal welfare

The website should make visitors immediately understand:

“I can help this animal.”

Every major page should have a clear and meaningful call-to-action.

2. BRAND IDENTITY

Brand name:

SaveStreet Dogs

Suggested tagline:

“Street by street. Paw by paw. Saving lives.”

33. SECURITY

Implement secure development practices.

Important:

- Validate all form inputs
- Sanitize user-generated content
- Protect admin routes
- Never expose secrets in frontend code
- Use environment variables
- Secure file uploads
- Restrict upload types
- Rate-limit sensitive endpoints where appropriate
- Do not expose personal information
- Do not store payment card information directly

Create ".env.example".

Never put API keys or secrets directly into source code.
